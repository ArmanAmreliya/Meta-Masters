## 🔥 Project Overview

PackPal is a web-based logistics organizer tailored for group travel, events, or any situation where multiple people need to coordinate packing. It eliminates confusion, assigns item responsibility, and tracks progress — all in real-time!

---

## 🚀 Features

- 👥 **Role-Based Access** – Owner, Admin, Member, Viewer
- 📋 **Categorized Checklists** – Hygiene, Tech, Documents, Food, etc.
- ✅ **Track Item Status** – Packed / Delivered
- 🔔 **Real-Time Updates** – Stay in sync with your team
- 📄 **PDF Export** – Download your checklist for offline use
- 🧰 **Templates** – Start with pre-built checklists to save time
